# Rook Courtship Codex

A tiny installable Progressive Web App (PWA) for phone and desktop.

Features
- 16 handcrafted offerings.
- Procedurally generated offerings assembled from many object, placement, presentation, and intent combinations.
- Four interpretation categories: Affection, Seduction, "I saw this and thought of you", and "Please do not ask where I obtained this".
- Local codex/progress saved on-device.
- Offline support after first successful load.
- Optional tiny local click tone.
- No account, server, analytics, or remote data required.

## Install on a phone

Once GitHub Pages is enabled for this repository, open the HTTPS site on your phone.

- Android / Chrome: menu -> Install app or Add to Home screen.
- iPhone / iPad / Safari: Share -> Add to Home Screen.

After the first successful load, the app can work offline.
